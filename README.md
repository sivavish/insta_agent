# InstaAgent 🚀  
### AI-Powered Trend-Aware Social Media Content Generator

InstaAgent is an AI-driven social media assistant designed to help creators generate high-performing content based on current trends and niche-specific engagement patterns.

The platform automates the process of creating captions, hashtags, posting strategies, and AI-generated visuals, enabling creators to streamline content production and improve audience engagement.

---

## ✨ Features

- AI-generated social media captions
- Smart hashtag generation
- Niche-based content recommendations
- Trend-aware content generation
- AI-powered image creation
- Multiple visual styles support
- Automated posting tips & engagement suggestions
- Streamlit-based interactive UI

---

## 🧠 Core Idea

Instead of manually researching trends and creating content from scratch, InstaAgent analyzes trending topics and generates optimized social media content tailored to a selected niche.

The system combines:
- trend-based prompt generation
- AI caption writing
- hashtag optimization
- visual generation workflows

to simplify the content creation pipeline for creators and brands.

## ▶️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/insta_agent.git
cd insta_agent
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Add Environment Variables

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key_here
```

### Run Application

```bash
streamlit run app.py
```
